# TSO Client

Tento verejný distribúaný repozitár obsahuje skompilovaný herný klient `client.swf`.

Zdrojové kódy, build skripty a projektová konfigurácia nie sú súčasťou tohto repozitára.

## Použitie

Stiahnite súbor [`client.swf`](client.swf) a nastavte svoj kompatibilný TSO launcher alebo aktualizačný program tak, aby používal tento súbor. Na priame automatické sťahovanie možno použiť Raw URL súboru z vetvy `main`.

Používateľsky viditeľné rozdiely oproti pôvodnému klientovi sú uvedené v [`CHANGES.md`](CHANGES.md).
